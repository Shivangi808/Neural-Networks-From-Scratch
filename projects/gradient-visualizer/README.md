# Gradient Visualizer

## Objective

Visualize how gradient descent moves toward the minimum of a mathematical function.

## Concepts

- Derivatives
- Gradients
- Learning Rate
- Gradient Descent
- Optimization

## Function

f(x) = x²

## Derivative

f'(x) = 2x

## Gradient Descent Rule

x_new = x - learning_rate × gradient

## Libraries

- NumPy
- Matplotlib

## How It Works

1. Start from an initial value.
2. Calculate the gradient.
3. Move in the opposite direction.
4. Repeat for a fixed number of steps.
5. Visualize the path toward the minimum.
