# Vector Playground

An interactive learning project for understanding scalars, vectors, and vector operations using Python and NumPy.

## Current Features

- Scalar creation
- Vector creation
- Vector addition
- Vector subtraction
- Scalar multiplication
- NumPy dot product
- Manual dot product implementation
- Comparison between NumPy and manual implementation

## Tech Stack

- Python
- NumPy
